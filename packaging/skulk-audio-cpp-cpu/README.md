# Skulk audio.cpp CPU engine

This separately installed wheel contains audio.cpp v0.8.2 at source commit
4d88768fbcae4e6eb3352c6ab1422dabb7d90b58, compiled for only the
ACE-Step and MiniMax Music 3 families. It carries the two loader model specs
and upstream Apache-2.0 and incorporated third-party licenses. Model weights are downloaded separately by
Skulk from immutable registry cards.

The CPU binary is available for Apple Silicon macOS 15+, Linux amd64, and
Linux arm64. Package availability does not assert that either model has been
qualified on any of these hosts.
